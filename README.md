#  Product Management App

A server-side rendered web application built using **Node.js**, **Express**, and **EJS**, following the **MVC architecture**.

---

##  Features

- Add new products with title, image URL, price, and description
- View all products in a structured grid layout
- View detailed product pages
- File-based data persistence using JSON
- Clean separation of concerns using MVC pattern

---

##  Tech Stack

- **Backend:** Node.js, Express
- **Templating:** EJS
- **Styling:** CSS
- **Storage:** File system (`fs` module, JSON-based)

---

## To Get Started:

### 1. Clone the repository

```bash
git clone https://github.com/Rishav256/NodeApp.git
cd NodeApp
```

### 2. Install dependencies

```bash
npm install
```

### 3. Run the app

```bash
npm start
```

App will run on:

```
http://localhost:3000
```
